## Record boundaries

The current behavior guides are README, local development, architecture/data
ownership, catalogs, hunts, photo entry, CI, security, failure recovery and
operations. The roadmap, requirements, PM status, dated closeouts, candidate
reviews and named assignment files are planning or evidence records. Their
workspace references and candidate-specific commands are provenance, not public
setup dependencies. Historical operator scripts retain exact inputs and safety
checks; they are not substitutes for the documented portable startup commands.
