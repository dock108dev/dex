## Implemented workflow

`/product-review/` is an owner-only, CSRF-protected retained/manual `dex-sealed-v1` package review surface over existing `sealed_imports`, mappings, source records, observations, bridges and correction/rollback journals. Preview displays stable IDs, package hash, new-record counts, unknown fields, source limitations, exact records and before/after corrections. Verify and publish remain explicit separate actions. Repeated confirmation is idempotent. Competing reviews refuse publication without clobbering later data; the browser displays the refusal and offers a fresh preview. Source review is an operator responsibility; structural verification is not independent review.

Membership corrections can change **status and provenance**, retaining old sources and adding applicable official evidence. Changed distribution/quantity/contents claims must be supported by newly added applicable official sources; an old source cannot establish a corrected assertion. Promo/deck assertions specifically require distribution evidence, rather than a booster checklist. Known booster, promo and deck-only status requires usable official card/distribution evidence, matching exact printing language and a physical expansion. Provider/card-list existence is insufficient. Source version, time, hash, subjects, supports and uncertainty remain in the existing package and source model. Membership identity/printing/expansion cannot be repurposed. M2 set/species distribution reporting follows current published corrections and restores after rollback, while historical packages remain frozen.

Exact product identities retain SKU, version, market and language. Quantities require official contents evidence; retailer descriptions cannot supply official pack quantities. A documented product with **zero boosters** can contain separately guaranteed printings. Mixed-known contents require reconciled expansion-specific quantities and a guaranteed-card review. Unknown pack quantities/assortments remain unknown. Guaranteed records have separate official applicability and never create booster membership.

Pack lookup accepts species, printing, selected targets, custom goal and missing-only scope, including owned and Johto targets. It displays exact products, pack breakdown, guarantees, seller/direct-versus-marketplace identity, price/currency/shipping and original dates. Product coverage deduplicates species across all documented matching expansions and separately reports possible, guaranteed and combined targets. Unknown quantities add no documented pull coverage. Guaranteed-only products appear even without a booster relationship. Existing price filters/order remain item-price comparisons within explicit currency; no best-value, pull probability or completion-cost claim is introduced.

Recommendation eligibility checks usable evidence for the **selected latest observation**, exact seller/product identity, official product identity, documented contents and selected-target applicability, observed stock, item price and original checked time within the inclusive 24-hour window. Missing/future/stale times, unavailable stock, missing price/evidence and synthetic/replay evidence cannot qualify a real recommendation. Unknown shipping is displayed honestly and prevents a delivered-total claim; it does not invent free shipping. The older `purchase_ready` gate still additionally requires verified fresh backend availability; manual imports never manufacture that attestation. Synthetic `behavior_eligible` is diagnostic qualification only and is visibly separated from real recommendation eligibility.

Original observation time may explicitly be null. No import, reopen, server start or tool-read time fills it. Immutable IDs and original observations survive newer observations; changing an observation requires a new ID/time, not a correction. The latest dated observation controls filtering and eligibility; a newer unavailable observation cannot leave an old in-stock observation current.

Saved research keeps frozen goal/source/catalog versions, exact product/offer/observation references and filters. Reopen only ages the retained timestamps and reports changed/archived references; it never imports current data. Changed saved references disable current recommendations. **Compare with current indexed data** opens an explicit new lookup with the selected scope and filters, leaving the original snapshot untouched. Frozen goals only include new printings through explicit new goals/successors. Cross-account saved references remain inaccessible.
