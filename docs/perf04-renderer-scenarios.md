The suites execute the shipped `bounded-reads.js`, `card-screens.js` and
`species-screens.js` with jsdom, not a transport-only substitute. Detail assertions
open their actual paged disclosures. Late response tests still deliver out of order.
The V2 adapter provides scoped evidence instead of the legacy global catalog evidence
array. Separate backend tests verify actual authorization and projection contracts.
The dependency is pinned in package-lock.json and installed in the required CI step.
